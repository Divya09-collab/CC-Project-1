# Frontend

React + Vite presentation layer. Run `npm install` then `npm run dev`.

For local development, leave `VITE_API_URL` blank in `.env`; the app will use `http://localhost:5000/api`.

For deployment, set `VITE_API_URL` to `https://cc-project-1-1.onrender.com/api` in Netlify. Build command: `npm run build`; publish directory: `dist`.
